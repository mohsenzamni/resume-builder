# ResumeCraft

A lightweight, English-language, left-to-right resume builder. Edit your details with a live preview, save a draft locally in your browser, and use your browser's print dialog to save a PDF.

## Run locally

Run `npm start` from the project directory, then open [http://localhost:4173](http://localhost:4173).

No packages or account are required. Drafts are saved in the current browser's local storage; clearing browser data removes them. Select **Download PDF** and choose **Save as PDF** in the print dialog.
